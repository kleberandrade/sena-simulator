Unity autonomous-vehicle simulator for artificial-intelligence education.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Scenes/Demo.unity](https://github.com/kleberandrade/sena-simulator/blob/master/Assets/Scenes/Demo.unity).

## Recorded requirements
